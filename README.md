# Dissertation: Evaluating Large Language Models for NPC Interaction in Games
## Structure
- `client` contains source code for the murder mystery game
- `report` contains all text, diagrams, references required to build the report
- `results` contains anonymised user participation data and self testing

## Abstract
Linear dialogue trees are a common occurrence in video games, providing an interesting story similar to a book or film, improving the experience through NPCs and cut-scenes.
With games, we have the option of branching dialogue trees giving players choice within games, increasing replayability at the cost of developer work.
What if games could generate dialogue in real-time allowing for unlimited possibilities.
The primary aim is to evaluate whether LLMs could be used to generate dialogue by creating a murder mystery game with both scripted and LLM powered dialogue,
improve LLM performance using techniques such as prompt-engineering to ground LLM knowledge to improve coherency and consistency and conduct a user evaluation compare a
scripted and LLM powered dialogue to measure improvements in narrative consistency and player engagement.
The model used is Qwen3.6-35b-a3b quantised to q4_K_M running externally to the client, using Pygame, written in python and participants asked to test both dialogue versions.
The results suggesting that LLMs have the potential to enhance game experiences through NPCs but I was unable to reach where it would be considered viable.
